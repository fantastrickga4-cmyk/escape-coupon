관리자용 사용 설명서

방탈출 쿠폰 — 발행 · 발송 · 추천 · 현황 관리 전체 가이드
로그인: 관리자 비밀번호 입력
1

대시보드 한눈에 보기

총 발급 · 사용 완료 · 미사용 수치와 호점별 사용을 확인. 실시간 최근 사용 내역이 15초마다 자동 갱신됩니다.
2

사용 취소(되돌리기)

직원이 잘못 처리한 쿠폰은 최근 사용 내역의 사용 취소로 미사용 상태로 복구. 모든 이력은 로그로 남습니다.
3

새 캠페인 발행 (쿠폰 만들기)

쿠폰 유형 선택 → 혜택·유효기간·수량 입력 → 발행하기
유형: 일반리뷰 작성 보상친구 추천
“▸ 사용 조건 설정” 펼치면 → 요일 한정시간대 한정(예 14~17시)최소 인원(단체)
4

🚪 테마(방) 관리

우리 매장 테마(공포관·추리관 등)를 등록·삭제. “다른 테마 유도” 쿠폰과 직원 사용 화면에 쓰입니다.
5

⏰ 빈 시간대 채우기

평일 낮처럼 한산한 때만 쓰는 쿠폰을 시간·요일 한정으로 발행해 빈 방을 채웁니다.
6

📩 문자로 쿠폰 보내기 (무료)

캠페인 선택 → 번호 붙여넣기(여러 개) → 발송 목록 만들기 → 번호별 문자 보내기(내 폰 문자앱이 내용까지 채워서 열림) 또는 복사.
“이미 플레이한 테마”를 고르면 그 테마 제외한 다른 테마 유도 쿠폰으로 발송됩니다.
👉 서버가 아니라 내 폰으로 발송이라 문자 무제한 요금제면 0원.
7

🤝 친구 추천 관리

① 유형 “친구 추천” 캠페인 생성(친구 혜택 + 추천인 보상) → ② 추천 링크 생성(추천인 번호 입력) → ③ 문자로 추천인에게 링크 전달.
친구가 링크에서 번호를 넣으면 친구 쿠폰 + 추천인 보상 쿠폰이 자동 발급됩니다. 발급된 보상도 목록에서 추천인에게 문자로 전달.
8

⭐ 리뷰 작성 보상

유형 “리뷰 보상” + 리뷰 링크 입력. 고객 쿠폰 화면에 리뷰 작성 버튼이 떠서 후기를 유도합니다.
9

캠페인 상세 · 추적

캠페인을 누르면 전체 링크 일괄 복사, 쿠폰별 사용/미사용·발송 번호 확인, 캠페인 삭제 가능.
💡 운영 팁
  • 발급 흐름 : 캠페인 발행 → 문자/추천으로 전달 → 고객 QR → 직원이 사용 처리.
  • 비용 0원 : 카카오/문자 API 대신 직원·사장 폰으로 직접 발송(문자 무제한 요금제 기준).
  • 시간 제한은 한국시간(KST) 기준으로 자동 판정됩니다.
  • 리뷰·추천 캠페인은 “미리 발급 수량 0”으로 두고, 발송/추천 시점에 쿠폰이 생성됩니다.
