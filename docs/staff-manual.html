직원용 사용 설명서

방탈출 쿠폰 — 고객 쿠폰을 “사용 처리”하는 방법
비밀번호 없음 · 호점만 선택하면 시작
1
호점 선택하고 입장
직원 화면에서 우리 매장을 누르고 들어가기 — 선택한 호점으로 사용 기록이 남습니다.
1호점2호점3호점
2
QR 스캔하기
카메라로 스캔 시작을 누르고, 고객 휴대폰의 쿠폰 QR을 비추면 자동 인식됩니다.
3
QR이 안 되면 코드 직접 입력
화면 맨 아래 입력칸에 쿠폰 코드를 입력하고 확인. (카메라 권한이 없거나 화면이 어두울 때)
4
추가 정보가 뜨면 입력
쿠폰 종류에 따라 입력창이 나옵니다 → 입력 후 사용 처리하기
• 인원수 : 단체 할인 쿠폰(예: 4인 이상)일 때 인원 입력
• 플레이 테마 : “다른 테마 유도” 쿠폰일 때 이번에 하는 테마 선택
5
결과 확인
✓ 사용 처리 완료 = 혜택 제공 OK / ✕ 거부 = 사용 불가
거부 사유 예시: 이미 사용됨유효기간 만료시간·요일 제한최소 인원 미달이미 플레이한 테마
6
다음 손님
다음 쿠폰 스캔을 누르면 바로 다음 고객을 처리할 수 있습니다.
⚠️ 꼭 기억하세요
  • 모든 쿠폰은 1회용 — 한 번 사용 처리하면 다시 못 씁니다.
  • 실수로 처리했다면 관리자에게 “사용 취소”를 요청하세요 (대시보드에서 되돌릴 수 있어요).
  • 같은 QR을 두 번 찍어도 딱 한 번만 처리됩니다 (걱정 마세요).
